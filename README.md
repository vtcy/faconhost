## 线路配置：这才是重点

说实话，现在市面上VPS的硬件配置都差不多，真正拉开差距的是网络线路。FaconHost在这方面确实下了功夫。

**美国洛杉矶机房**采用联通AS9929和移动CMIN2线路。AS9929这条线路的特点是延迟低、稳定性好，虽然带宽资源不如电信CN2 GIA那么充裕，但在性价比上有明显优势。测评数据显示，从国内访问洛杉矶节点，三网回程都走AS9929高端线路，平均延迟在150ms左右，晚高峰时期基本不丢包。

**新加坡机房**则是双向CN2 GIA线路，这条线路的级别更高。电信用户走CN2 GIA双向直连，联通和移动用户的回程也强制走CTG/CN2链路。实际测试中，国内三网访问新加坡节点的平均延迟在102ms左右，速度体验接近香港机房。关键是1Gbps的大带宽配置，这在亚洲节点中相当少见。

**香港机房**提供100Mbps带宽的三网直连线路，虽然带宽不如新加坡那么夸张，但对于建站和日常使用完全够用。延迟更是低到60ms以内，基本感觉不到延迟。

**荷兰机房**的线路配置是CN2 GIA + CUII/AS9929，这个组合主要服务欧洲和对欧洲业务有需求的用户。虽然从国内访问荷兰的延迟肯定高一些，但线路优化后的稳定性还不错。
